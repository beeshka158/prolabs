## Лабораторная работа № 2 «Программирование разветвляющихся и циклических алгоритмов с использованием функций в Python»

## Цель работы
Изучение синтаксиса и практических возможностей условных
операторов (if-elif-else), циклических конструкций (while, for..in) и
пользовательских функций (def) в языке Python. Приобретение навыков
декомпозиции алгоритмов управления, передачи аргументов и возврата
результатов вычислений.

## Краткие теоретические сведения
• Условный оператор if-elif-else: используется для проверки
логических условий и ветвления алгоритма. Конструкция elif позволяет
связывать несколько последовательных проверок без добавления лишней
вложенности отступов. Блок else выполняется, если ни одно из условий не
подтвердилось. Обязательным синтаксическим правилом является
использование двоеточия (:) и строгое соблюдение отступов (4 пробела).

• Цикл while: выполняет блок выражений до тех пор, пока проверяемое
условие истинно (True). Для экстренного выхода из цикла применяется
оператор break, а для перехода к следующей итерации — continue. При
естественном завершении цикла выполняются команды из необязательного
блока else.

• Цикл for..in и функция range(): осуществляет перебор элементов
последовательности (списков, строк или диапазонов). Встроенная функция
range(start, stop, step) генерирует арифметическую прогрессию
чисел, не включая верхнюю границу stop.

• Пользовательские функции (def): представляют собой многократно
используемые блоки кода с собственным именем. Функция объявляется с
помощью ключевого слова def, принимает параметры и возвращает
результаты вычислений оператором return. Строки документации
docstrings (в тройных кавычках) размещаются сразу после заголовка
функции для описания ее назначения.

## Задание
Вариант 6. Расход топлива турбины.
Разработать функцию vibration_diagnostic(vibe_data),
классифицирующую замеры виброскорости: V < 2.8 мм/с — «Замечательно»,
2.8 <= V < 7.1 — «Допустимо», V >= 7.1 — «Авария». Функция должна
возвращать процент аварийных замеров.

## Код программы:
```
def vibration_diagnostic(vibe_data):
#Функция классифицирует замеры виброскорости.
#vibe_data: список чисел (замеры)
if not vibe_data: # Проверка на пустой список
return 0.0
avaria_count = 0 # Счетчик аварий
for v in vibe_data:
# Классификация по условию
if v < 2.8:
status = "Замечательно"
elif 2.8 <= v < 7.1:
status = "Допустимо"
else: # v >= 7.1
status = "Авария"
avaria_count += 1
# Вывод результата для каждого замера
print(f"Замер {v} мм/с: {status}")
# Расчет процента аварий
percent = (avaria_count / len(vibe_data)) * 100
return percent
#Тестирование программы
test_measurements = [1.5, 3.2, 8.0, 5.5, 7.5, 2.0, 9.1]
print(" Результаты диагностики")
result = vibration_diagnostic(test_measurements)
print(f"\nПроцент аварийных замеров: {result:.1f}%")
```
