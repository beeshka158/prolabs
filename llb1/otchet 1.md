Краткие теоретические сведения
Язык Python является интерпретируемым. При первом запуске код транслируется в промежуточный байт-код и выполняется виртуальной машиной. Переменные представляют собой ссылки (имена), связанные с объектами в динамической памяти. Отступы (ровно 4 пробела) обязательны и служат для группировки блоков кода. Метод format() позволяет выполнять форматирование в соответствии со спецификацией PEP 3101.
Например, выражение '{0:.3f}'.format(pi) форматирует вещественное число с точностью до трех знаков после запятой. Вместо метода format() можно использовать f-строки. «Настройка рабочей среды и базовый синтаксис»
 
Задание
Вариант 6. Сила Лоренца для движущегося заряда
Напишите скрипт, вычисляющий физическую величину по формуле. Все переменные должны быть динамически привязаны к значениям. Вывод результата осуществить с округлением вещественной части до 4 знаков после запятой. Исходные параметры ввести с помощью функции input().
Исходный код программы:
#запрос данных у пользователя
q = float(input("введите заряд q: ")) #float–превращ. текст в дробн. число
v = float(input("введите скорость v: ")) # input – получает текст
B = float(input("введите магнитную индукцию В: "))
F=q*v*B # формула силы Лоренца
print(f"сила лоренца: F = {F:.4f}") # print – выводит результат на экран

Результат:
введите заряд q: 1.6е-19
введите скорость v: 3е5
введите магнитную индукцию В: 0.5
сила лоренца: F = 0.0000
